## Root cause of the zero-test report

The Playwright CLI `--reporter=line` option replaces the reporter list configured in `playwright.config.ts`. A run with that override does not invoke the custom HTML reporter, leaving the prior report unchanged. The final report was regenerated with the project reporter and contains 128 actual test records: 125 passed, 3 skipped, and 0 failed. The HTML report totals are generated from Playwright test records; they are not hardcoded.
