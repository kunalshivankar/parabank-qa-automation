## Root cause of the zero-test report

The Playwright CLI `--reporter=line` option replaces the reporter list configured in `playwright.config.ts`. A run with that override does not invoke the custom HTML reporter, leaving the prior report unchanged. The final report was regenerated by running the selected projects without a CLI reporter override, allowing the configured glass reporter to write the current 118-test result. The HTML report totals are generated from Playwright test records; they are not hardcoded.
